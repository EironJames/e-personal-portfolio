EJ PERSONAL PORTFOLIO - HTML AND CSS ONLY

FILES
- index.html: webpage structure and content
- style.css: colors, layout, cards, and hover effects
- index_html_code.txt: copy of index.html
- images/: supplied profile photo and certificate images

HOW TO USE
1. Keep index.html, style.css, and images folder together.
2. Open index.html in a browser to preview.
3. Edit text in index.html.
4. Edit colors and appearance in style.css.
5. Save changes and upload the updated files to GitHub.

IMPORTANT
- This version uses HTML and CSS only. It contains no JavaScript.
- Navigation links jump to page sections.
- Cards and links respond to hover.
- The mini challenges use HTML details/summary to reveal answers. They do not keep score or calculate results.
- Color theme samples are visual palette references; they are not an automatic theme switcher.
- Keep image filenames and capitalization exactly as shown in the images folder.
